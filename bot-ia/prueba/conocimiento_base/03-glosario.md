# Cómo hablan en el grupo (frase -> qué significa -> qué piden)

- "Foco suelto" / "tubo suelto" / "luminaria colgando" -> luminaria o tubo fluorescente mal fijado. ELEC. Fijarlo o cambiarlo.
- "Foco sin protección" / "tubo sin acrílico" -> luminaria sin protector. ELEC/INFRA. Poner protector.
- "Ventilador sin protección" / "extractor sin rejilla" -> extractor de aire de muro o cielo sin malla/rejilla. INFRA. Instalar rejilla o malla.
- "Malla no hermética" / "malla rota" / "mosquitero suelto" -> malla mosquitera de ventana con aberturas. INFRA. Reparar o cambiar y sellar.
- "No prende el horno / la cocina / el quemador" -> si es a gas: GAS (piloto, termopar); si es eléctrico: EQUIPO.
- "Olor a gas" / "fuga" -> GAS, emergencia: cerrar llave de paso, ventilar, va Camilo hoy.
- "No enfría" / "se descongeló" -> FRIO.
- "Gotea la llave" / "lavaplatos tapado" / "rebalsa la cámara" -> AGUA.
- "Saltó el automático" / "sin luz en la cocina" / "enchufe quemado" -> ELEC.
- "La campana no tira" -> EQUIPO (campana de extracción de la cocina).
- "Cielo con humedad" / "pintura saltada" / "descascarado" -> INFRA (campaña de pintura de cocinas).
- "Verificador" -> PDF de la bitácora de una visita.
- "Viene la SEREMI" / "supervisión JUNAEB" / "auditoría" / "fiscalización" -> AVISO: priorizar lo pendiente de ese establecimiento.
- "¿Cuándo van?" / "¿qué pasó con…?" -> PREGUNTA por el estado de algo ya pedido.
- "No llegaron" / "el técnico se fue sin avisar" -> RECLAMO.
- Un mensaje con solo el nombre del colegio ("Republica de brasil") se refiere a las fotos/frases de la misma
  supervisora justo antes o justo después.
